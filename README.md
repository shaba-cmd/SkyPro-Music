## Музыкальный сервис SkyPro Music

Музыкальный сервис: каталог треков, подборки, избранное и плеер.

## Стек

Next.js 16 (App Router), TypeScript, Redux Toolkit, axios, Framer Motion, CSS Modules.

## Деплой

...

## Запуск

```bash
npm install
npm run dev
```

Приложение поднимется на http://localhost:3000

## Возможности

- Регистрация и вход, хранение сессии между перезагрузками
- Автоматическое обновление access-токена (живёт 200 секунд)
- Защита маршрутов `/music/*`
- Каталог треков, подборки, поиск по названию и исполнителю
- Фильтры по исполнителю, жанру и году выпуска
- Избранное: добавление и удаление треков
- Плеер: воспроизведение, перемотка, громкость, повтор, перемешивание

## Структура

src/
├── app/ маршруты
├── components/ компоненты
├── hooks/ пользовательские хуки
├── services/ работа с API
